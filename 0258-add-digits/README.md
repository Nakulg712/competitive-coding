<h2> <a href="https://leetcode.com/problems/add-digits"> 258. Add Digits </a> </h2> <h3>Easy</h3> <hr> <p> Given an integer <code>num</code>, repeatedly add all its digits until the result has only one digit, and return it. </p> <p> You must solve the problem without using loops or recursion. </p> <br> <h3>💡 Intuition</h3> <p> We need to repeatedly add the digits of a number until only one digit remains. </p> <p> For example, if <code>num = 38</code>: </p> <pre> 38 → 3 + 8 = 11 11 → 1 + 1 = 2 </pre> <p> So the answer is <strong>2</strong>. </p> <p> There is a mathematical shortcut called the <strong>Digital Root</strong>. </p> <p> The digital root of a positive number can be calculated using: </p> <pre> 1 + (num - 1) % 9 </pre> <p> There is one special case: if <code>num = 0</code>, the answer is <code>0</code>. </p> <p> Therefore, we do not need any loop or recursion. </p> <h3>🔹 Approach</h3> <ol> <li> If <code>num == 0</code>, return <code>0</code>. </li> <li> Otherwise, calculate the digital root using: <pre>1 + (num - 1) % 9</pre> </li> <li> Return the calculated value. </li> </ol> <p> <strong>Why does this work?</strong> </p> <p> Every number has the same remainder modulo <code>9</code> as the sum of its digits. </p> <p> For example: </p> <pre> 38 % 9 = 2 3 + 8 = 11 11 % 9 = 2 </pre> <p> So repeatedly adding the digits eventually gives the same digital root. </p> <h3>🧠 C++ Code</h3> <pre> class Solution { public: int addDigits(int num) { if (num == 0) return 0; return 1 + (num - 1) % 9; } }; </pre> <h3>⏱️ Time Complexity</h3> <p> <strong>O(1)</strong> </p> <p> We perform only a few mathematical operations, regardless of the size of <code>num</code>. </p> <h3>💾 Space Complexity</h3> <p> <strong>O(1)</strong> </p> <p> Only a few variables are used, so no extra memory is required. </p> <br> <p><strong class="example">Example 1:</strong></p> <pre> <strong>Input:</strong> num = 38 <strong>Output:</strong> 2 <strong>Explanation:</strong> 38 → 3 + 8 = 11 11 → 1 + 1 = 2 </pre> <p><strong class="example">Example 2:</strong></p> <pre> <strong>Input:</strong> num = 0 <strong>Output:</strong> 0 <strong>Explanation:</strong> The digital root of 0 is 0. </pre> <br> <p><strong>Constraints:</strong></p> <ul> <li><code>0 &lt;= num &lt;= 2<sup>31</sup> - 1</code></li> </ul> <hr> <h3>🎯 Quick Revision</h3> <table border="1" cellpadding="8"> <tr> <th>Topic</th> <th>Answer</th> </tr> <tr> <td>Technique</td> <td>Digital Root / Mathematics</td> </tr> <tr> <td>Goal</td> <td>Reduce number to a single digit</td> </tr> <tr> <td>Formula</td> <td>1 + (num - 1) % 9</td> </tr> <tr> <td>Time Complexity</td> <td>O(1)</td> </tr> <tr> <td>Space Complexity</td> <td>O(1)</td> </tr> </table> <br> <h3>🧠 One-Line Interview Intuition</h3> <p> <strong> "Instead of repeatedly adding digits, use the digital root formula 1 + (num - 1) % 9 to get the answer directly in O(1) time." </strong> </p>
